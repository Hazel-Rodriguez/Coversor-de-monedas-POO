**Convertidor de Monedas**  
¡Bienvenido al Convertidor de Monedas! Este programa desarrollado en Java te permite transformar valores entre diferentes divisas, como el Dólar Estadounidense, el Peso Argentino, el Real Brasileño y el Peso Colombiano.

Utiliza la poderosa API **ExchangeRate**, que ofrece tasas de conversión en tiempo real, asegurando que las operaciones reflejen los cambios más recientes en el mercado.

Esta API es gratuita y está disponible para estudiantes, desarrolladores, ingenieros y cualquier persona interesada en realizar conversiones rápidas, precisas y actualizadas.

### **Características principales**
- **Soporte para múltiples monedas:** Convierte fácilmente entre Dólar, Peso Argentino, Real Brasileño y Peso Colombiano en ambas direcciones.
- **Actualizaciones en tiempo real:** Aprovecha la funcionalidad de **ExchangeRate-API** para obtener tasas de cambio vigentes al momento de realizar la consulta.
- **Interfaz intuitiva:** Un menú sencillo que permite interactuar de manera ágil y eficiente.
- **Gestión de errores:** Implementa excepciones que garantizan un funcionamiento robusto ante posibles inconvenientes en las solicitudes a la API.
- **Opción de salida:** El programa incluye una opción específica para finalizar la ejecución, evitando reinicios innecesarios entre conversiones.

### **Tecnologías utilizadas**
1. **Java 22.0.2**
2. **Gson**
3. **ExchangeRate-API**
